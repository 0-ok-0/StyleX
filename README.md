# StyleX · лаунчер для Android (тема 09)

Нативная оболочка на Kotlin + интерфейс темы 09 «Стрелиция» внутри WebView. Настоящие приложения и ярлыки, счётчики и шторка из уведомлений, мини-плеер, погода, календарь, блокировка двойным тапом, заставка AOD.

## Как получить APK через GitHub
1. Создай репозиторий на GitHub (можно приватный).
2. Загрузи в корень репозитория всё содержимое папки `StreliziaLauncher`, включая скрытую папку `.github`. Проще всего через git:
   ```
   cd StreliziaLauncher
   git init
   git add .
   git commit -m "Стрелиция"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
   Если грузишь через сайт (Add file → Upload files), скрытая `.github` может не попасть. Тогда создай файл `.github/workflows/build.yml` вручную (Add file → Create new file) и вставь его содержимое из архива.
3. Вкладка **Actions** → **Build APK** запустится сама (или нажми Run workflow). Сборка идёт 5-10 минут.
4. Открой готовый запуск → внизу **Artifacts** → `strelizia-launcher-apk`. Внутри `app-release.apk`.
5. Поставь APK на телефон (разреши установку из этого источника).

## Первая настройка
Лаунчер сам покажет экран «первый запуск», всё это потом есть в настройках (удержи пустое место на обоях → раздел Android):
- **Сделать рабочим столом**: кнопка «Домой» будет открывать Стрелицию.
- **Доступ к уведомлениям**: счётчики, шторка, плашки, мини-плеер.
- **Спецвозможности → «Стрелиция: блокировка»**: двойной тап по обоям блокирует экран, отпечаток работает как обычно.
- **Календарь** и **геолокация или город**: события и погода (Open-Meteo, без ключей).
- **Изменение системных настроек**: ползунок яркости в шторке.
- **Батарея: без ограничений** и **Автозапуск** в HyperOS, чтобы система не выгружала лаунчер.
- **Заставка AOD**: Настройки → Экран → Заставка → Стрелиция (если пункт есть в твоей прошивке).

## Обновления
Все сборки подписаны одним ключом `app/strelizia.p12`, поэтому новый APK ставится поверх старого без потери настроек. Не удаляй и не меняй этот файл.

## Ограничения Android и HyperOS
- Экран блокировки и AOD HyperOS заменить нельзя, у сторонних лаунчеров нет такого доступа.
- Системная шторка остаётся, шторка Стрелиции дополнительная.
- Wi-Fi, Bluetooth и режим полёта приложениям переключать запрещено: плитки открывают системные панели.
- Жесты HyperOS со сторонним лаунчером иногда ведут себя иначе (анимация «домой», недавние).
- Только для личного использования: это фан-арт, в Google Play такое не выложить.

## Android Studio (вместо GitHub)
Открой папку `StreliziaLauncher`, JDK 17, Gradle 8.9 (Studio возьмёт его из `gradle/wrapper/gradle-wrapper.properties`), затем Build → Build APK(s).
